# Решение

## Как запустить

Нужен Python 3.9+, устанавливать ничего не надо.

```
python3 report.py --date 2026-11-10                    # таблица в консоли
python3 report.py --date 2026-11-10 --csv report.csv   # плюс CSV для Excel (разделитель ;)
python3 report.py --date 2026-11-10 --data path/to/data
python3 -m unittest -v                                 # тесты
```

## Файлы

- `report.py` - программа.
- `test_report.py` - тесты: 10.11.2026, а также 05.09 (до возврата P-2) и 12.11 (переплата по D-2).
- `DECISIONS.md` - решения и допущения.
- `NOTE.md` - записка бухгалтеру.
